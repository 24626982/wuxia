# 西院南側石牆

使用內建 image_gen 編輯西院背景，輸出 `residence-fenced.png`（1672 × 941）。依使用者修正，將先前新增的竹木圍籬替換為與兩側原有石牆一致的灰色矮石牆。

提示：只替換底部中央石路上的棕色竹木圍籬（約 x=615–985、y=793–880），改為與左右原有庭園石牆一致的低矮灰石欄牆：灰色風化石材、內凹矩形雕飾、水平壓頂石、帶圓形雕花柱帽的短石柱與少量青苔。尺寸、透視、高度及像素畫風與原石牆一致，底部約 y=875，頂部約 y=805，兩端自然接入竹叢，不設門或缺口。完整保留其他建築、池塘、石路、中央圓紋、竹林與右側石橋，不加入文字、介面或人物。

`residence.tscn` 使用此圖，南側碰撞由 `Obstacles/SouthWall` 封閉，與兩側既有庭園／池塘碰撞相接。
